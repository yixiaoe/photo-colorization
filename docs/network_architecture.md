# 网络架构说明

**更新日期：** 2026/05/19  
**覆盖范围：** Phase 1（CnnColorGenerator）、Phase 2（InstanceGenerator / FiLMInstanceGenerator / WeightGenerator / FusionPipeline）

---

## 符号约定

```
(N, C, H, W)  —  批次 × 通道 × 高 × 宽
::2           —  步长为 2 的下采样切片（等价于 stride=2，但不含可训参数）
d=2           —  膨胀卷积 dilation=2
↑2            —  ConvTranspose2d，步长 2，空间尺寸 ×2
```

## Phase 1：CnnColorGenerator（Zhang et al. 2016）

**任务：** 全图灰度 → 313 个 ab 色彩 bin 的概率分布  
**训练损失：** rebalanced 交叉熵  
**推理解码：** annealed-mean（温度 T=0.38）

```
输入: 全图灰度 L 通道  (1, 1, 256, 256)
  │
  ▼
┌──────────────────────────────────────────────────────────────┐
│  model1  Conv(1→64, s=1) + BN + ReLU                         │
│          Conv(64→64, s=2) + BN + ReLU          ← 步长2下采样  │
└──────────────────────────────────────────────────────────────┘
  │  (1, 64, 128, 128)
  ▼
┌──────────────────────────────────────────────────────────────┐
│  model2  Conv(64→128, s=1) + BN + ReLU                       │
│          Conv(128→128, s=2) + BN + ReLU        ← 步长2下采样  │
└──────────────────────────────────────────────────────────────┘
  │  (1, 128, 64, 64)
  ▼
┌──────────────────────────────────────────────────────────────┐
│  model3  Conv(128→256) × 2 + Conv(256→256, s=2) + BN + ReLU │
└──────────────────────────────────────────────────────────────┘
  │  (1, 256, 32, 32)
  ▼
┌──────────────────────────────────────────────────────────────┐
│  model4  Conv(256→512, d=1) × 3 + BN + ReLU   ← 保持分辨率   │
└──────────────────────────────────────────────────────────────┘
  │  (1, 512, 32, 32)
  ▼
┌──────────────────────────────────────────────────────────────┐
│  model5  Conv(512→512, d=2) × 3 + BN + ReLU   ← 膨胀感受野   │
└──────────────────────────────────────────────────────────────┘
  │  (1, 512, 32, 32)
  ▼
┌──────────────────────────────────────────────────────────────┐
│  model6  Conv(512→512, d=2) × 3 + BN + ReLU                  │
└──────────────────────────────────────────────────────────────┘
  │  (1, 512, 32, 32)
  ▼
┌──────────────────────────────────────────────────────────────┐
│  model7  Conv(512→512, d=1) × 3 + BN + ReLU                  │
└──────────────────────────────────────────────────────────────┘
  │  (1, 512, 32, 32)
  ▼
┌──────────────────────────────────────────────────────────────┐
│  model8  ConvTranspose(512→256, ↑2) + Conv×2 + BN + ReLU     │
└──────────────────────────────────────────────────────────────┘
  │  (1, 256, 64, 64)
  ▼
┌──────────────────────────────────────────────────────────────┐
│  model_out  Conv(256→313, 1×1)                                │
└──────────────────────────────────────────────────────────────┘
  │
  ▼
输出: ab bin 概率 logits  (1, 313, 64, 64)   ← H/4 分辨率
        │
        ▼ annealed-mean 解码 + 双线性上采样
输出: ab 通道  (1, 2, 256, 256)  → 与 L 拼合 → RGB
```

**参数量估计：** ~33M（与原版 Caffe 模型等价）

## Phase 2 Stage-full：InstanceGenerator（Su et al. CVPR 2020 骨干）

**任务：** 全图灰度 → ab 分类（H/4）+ ab 回归（全分辨率）  
**与 Phase 1 的关键差异：**
- 下采样改用无参数切片 `::2`（可精确对齐 skip connection）
- 解码器有 3 级 skip connection（conv1/conv2/conv3 → conv10/conv9/conv8）
- 输出同时包含分类头（313-bin）和回归头（ab Tanh），提供两种监督信号

```
输入: 全图灰度 L 通道  (1, 1, 256, 256)
  │
  ▼
┌──────────────────────────────────────────────────────────────────┐
│  conv1  Conv(1→64)×2 + BN + ReLU                                 │
│         无步长 ── 全分辨率特征，保留最细节的空间信息               │
└──────────────────────────────────────────────────────────────────┘
  │  conv1_2  (1, 64, 256, 256)  ◀──────────────────────── skip A
  │  [:,:,::2,::2]  → (1, 64, 128, 128)
  ▼
┌──────────────────────────────────────────────────────────────────┐
│  conv2  Conv(64→128)×2 + BN + ReLU                               │
└──────────────────────────────────────────────────────────────────┘
  │  conv2_2  (1, 128, 128, 128)  ◀─────────────────────── skip B
  │  [:,:,::2,::2]  → (1, 128, 64, 64)
  ▼
┌──────────────────────────────────────────────────────────────────┐
│  conv3  Conv(128→256)×3 + BN + ReLU                              │
└──────────────────────────────────────────────────────────────────┘
  │  conv3_3  (1, 256, 64, 64)  ◀───────────────────────── skip C
  │  [:,:,::2,::2]  → (1, 256, 32, 32)
  ▼
┌──────────────────────────────────────────────────────────────────┐
│  conv4  Conv(256→512, d=1)×3 + BN + ReLU                         │
└──────────────────────────────────────────────────────────────────┘
  │  (1, 512, 32, 32)
  ▼
┌──────────────────────────────────────────────────────────────────┐
│  conv5  Conv(512→512, d=2)×3 + BN + ReLU  ← 膨胀感受野 = 32px   │
└──────────────────────────────────────────────────────────────────┘
  │  (1, 512, 32, 32)
  ▼
┌──────────────────────────────────────────────────────────────────┐
│  conv6  Conv(512→512, d=2)×3 + BN + ReLU                         │
└──────────────────────────────────────────────────────────────────┘
  │  (1, 512, 32, 32)
  ▼
┌──────────────────────────────────────────────────────────────────┐
│  conv7  Conv(512→512, d=1)×3 + BN + ReLU                         │
└──────────────────────────────────────────────────────────────────┘
  │  (1, 512, 32, 32)
  │
  │         ┌────────────────────────────────┐
  ▼         │  分类头（从 conv8_3 分叉）      │
┌───────────┴──────────────────────────────────────────────────────┐
│  conv8up  ConvTranspose(512→256, ↑2) + skip C  ← 加上 conv3_3    │
│  conv8    Conv(256→256)×2 + BN + ReLU                             │
└──────────────────────────────────────────────────────────────────┘
  │  conv8_3  (1, 256, 64, 64)
  ├──→  Conv(256→313, 1×1)  →  out_class  (1, 313, 64, 64)  【分类输出】
  ▼
┌──────────────────────────────────────────────────────────────────┐
│  conv9up  ConvTranspose(256→128, ↑2) + skip B  ← 加上 conv2_2    │
│  conv9    Conv(128→128) + BN + ReLU                               │
└──────────────────────────────────────────────────────────────────┘
  │  conv9_3  (1, 128, 128, 128)
  ▼
┌──────────────────────────────────────────────────────────────────┐
│  conv10up  ConvTranspose(128→128, ↑2) + skip A  ← 加上 conv1_2   │
│  conv10    Conv(128→128) + LeakyReLU(0.2)                         │
└──────────────────────────────────────────────────────────────────┘
  │  conv10_2  (1, 128, 256, 256)
  ▼
┌──────────────────────────────────────────────────────────────────┐
│  model_out  Conv(128→2, 1×1) + Tanh                               │
└──────────────────────────────────────────────────────────────────┘
  │
  ▼
out_class  (1, 313, 64, 64)  ← CE 损失监督（H/4 分辨率）
out_reg    (1, 2,   256, 256) ← Huber 损失监督（全分辨率）
```

**Skip connection 作用：** 解码时融入浅层精确空间信息（边缘/纹理），避免解码器上采样后颜色边界模糊。

## Phase 2 Stage-instance：FiLMInstanceGenerator

**任务：** 实例 crop 灰度 + GT 类别标签 → ab 预测  
**与 InstanceGenerator 的唯一差异：** conv4–conv7 后各插入一个 FiLM 调制层

```
输入: 灰度实例图 (1, 1, 256, 256) + 标签 "dog"（类别 id = 18）
  │
  ▼
  conv1 ──→ (1, 64, 256, 256)        ← 低级边缘，不调制
    │ ::2
  conv2 ──→ (1, 128, 128, 128)       ← 低级纹理，不调制
    │ ::2
  conv3 ──→ (1, 256, 64, 64)         ← 中级模式，不调制
    │ ::2
  conv4 ──→ (1, 512, 32, 32)
  ╔══════════════════════════════════════════════════════════╗
  ║  FiLM 调制层（film4）                                    ║
  ║                                                          ║
  ║  标签 18                                                 ║
  ║    ↓  nn.Embedding(91, 64)                               ║
  ║  emb          → (1, 64)         ← 可学习的类别向量       ║
  ║    ↓  nn.Linear(64, 2×512)                               ║
  ║  params       → (1, 1024)                                ║
  ║    ↓  chunk(2)                                           ║
  ║  γ            → (1, 512)        ← 通道缩放偏移量         ║
  ║  β            → (1, 512)        ← 通道平移偏移量         ║
  ║    ↓  unsqueeze(-1).unsqueeze(-1)                        ║
  ║  γ            → (1, 512, 1, 1)  ← 广播到空间维度         ║
  ║  β            → (1, 512, 1, 1)                           ║
  ║                                                          ║
  ║  特征' = 特征 × (1 + γ) + β                              ║
  ║                                                          ║
  ║  (1,512,32,32) × (1,512,1,1) + (1,512,1,1)              ║
  ║       = (1, 512, 32, 32)        ← 维度完全不变！         ║
  ║                                                          ║
  ║  初始化：fc.weight=0, fc.bias=0                          ║
  ║  → 训练开始时 γ=0, β=0 → feat'=feat（恒等，不破坏权重）  ║
  ╚══════════════════════════════════════════════════════════╝
    ↓
  conv5 ──→ (1, 512, 32, 32)
  ╔═══════ FiLM 调制（film5，结构同上）═══════╗
  ╚═══════════════════════════════════════════╝
    ↓
  conv6 ──→ FiLM（film6）──→ (1, 512, 32, 32)
    ↓
  conv7 ──→ FiLM（film7）──→ (1, 512, 32, 32)
    ↓
  conv8 + skip C ──→ (1, 256, 64, 64)     ← 解码层，不调制
    ├──→ out_class  (1, 313, 64, 64)
    ↓
  conv9 + skip B ──→ (1, 128, 128, 128)
    ↓
  conv10 + skip A ──→ (1, 128, 256, 256)
    ↓
  out_reg  (1, 2, 256, 256)
```

**FiLM 参数量：**

| 模块 | 参数 |
|------|------|
| nn.Embedding(91, 64) | 91 × 64 = 5 824 |
| film4: Linear(64→1024) | 64×1024 + 1024 = 66 560 |
| film5: Linear(64→1024) | 66 560 |
| film6: Linear(64→1024) | 66 560 |
| film7: Linear(64→1024) | 66 560 |
| **FiLM 合计** | **~272K** |
| 骨干（InstanceGenerator） | ~32M |

**训练优化器分组：**
```
backbone 参数  →  lr = 5e-5  （加载了 Stage-1 权重，用小学习率微调）
FiLM 参数     →  lr = 1e-4  （随机初始化，用正常学习率学习）
```

## Phase 2 Stage-fusion：WeightGenerator（融合权重预测器）

**任务：** 在每个特征层对全图特征与各实例特征做软注意力加权融合  
**每个 WeightGenerator 处理一个特征层，共 13 个实例**

```
输入:
  inst_feat    (N, C, h, w)   ← N 个实例在本层的特征（来自 FiLMInstanceGenerator）
  bg_feat      (1, C, h, w)   ← 全图分支在本层的特征（来自 FusionPipeline 骨干）
  box_info     (N, 6)         ← 每个实例的 bbox 信息 [L_pad, R_pad, T_pad, B_pad, rw, rh]
                                 其中 rw, rh 是本层分辨率下 bbox 的宽高
  │
  ├── 对每个实例 i（共 N 个）:
  │     inst_crop_i = inst_feat[[i]]               (1, C, h, w)
  │     weight_i = instance_conv(inst_crop_i)      (1, 1, h_box, w_box)
  │         ↓  resize → (1, 1, rh, rw)，再 pad 到全图尺寸
  │     weight_i_full                               (1, 1, h, w)   ← 仅 bbox 区域非零
  │
  │     feat_i_full = resize_and_pad(inst_crop_i)   (1, C, h, w)
  │
  ├── 全图背景:
  │     bg_weight = bg_conv(bg_feat)                (1, 1, h, w)
  │     bg_weight += (1 − covered_mask) × 1e5      ← 无实例覆盖区域强制选背景特征
  │
  ├── 拼接并归一化:
  │     all_weights = cat([weight_0, ..., weight_N-1, bg_weight], dim=1)
  │                                                  (1, N+1, h, w)
  │     weights = Softmax(dim=1)(all_weights)        (1, N+1, h, w)
  │
  └── 加权求和:
        feat_stack  = cat([feat_0, ..., feat_N-1, bg_feat], dim=0)  (N+1, C, h, w)
        weights_t   = weights.permute(1, 0, 2, 3)                   (N+1, 1, h, w)
        fused       = sum(feat_stack × weights_t, dim=0, keepdim=True)
                                                                      (1, C, h, w)
输出: fused  (1, C, h, w)   ← 与输入 bg_feat 形状相同，可直接替换进骨干流
```

**WeightGenerator 参数量（per instance）：**  
`instance_conv`: Conv(C→16)→Conv(16→16)→Conv(16→1)，约 3K 参数  
`bg_conv`: 同结构，约 3K 参数  
**13 层合计：** ~78K（可训练）

## Phase 2 Stage-fusion：FusionPipeline（完整融合管线）

**可训练部分：** 仅 13 个 WeightGenerator + output_conv  
**冻结部分：** 骨干（与 InstanceGenerator 同结构）、FiLMInstanceGenerator

```
输入: gray_full    (1, 1, 256, 256)    ← 全图 L 通道
      inst_L       (N, 1, 256, 256)    ← N 个实例 L 通道（来自 Mask R-CNN 检测）
      class_labels (N,)                ← Mask R-CNN 预测的类别 id
      box_info_list: [bi_H, bi_H2, bi_H4, bi_H8]   各尺度下的 (N,6) bbox 信息

  │
  ├── FiLMInstanceGenerator（冻结）
  │   对每个实例 i 单独前向，收集 feature_map（共 13 个 key）
  │   inst_feats = [fm_0, fm_1, ..., fm_{N-1}]
  │
  └── FusionPipeline 骨干 + WeightGenerator 融合（以 256×256 为例）

骨干前向 + 逐层融合：

  gray_full  (1,1,256,256)
      ↓
  conv1_2  (1,64,256,256)   →  WG_conv1_2(inst, bg, bi_H)   →  fused (1,64,256,256)
      │::2
  conv2_2  (1,128,128,128)  →  WG_conv2_2(inst, bg, bi_H2)  →  fused (1,128,128,128)
      │::2
  conv3_3  (1,256,64,64)    →  WG_conv3_3(inst, bg, bi_H4)  →  fused (1,256,64,64)
      │::2
  conv4_3  (1,512,32,32)    →  WG_conv4_3(inst, bg, bi_H8)  →  fused (1,512,32,32)
  conv5_3  (1,512,32,32)    →  WG_conv5_3(inst, bg, bi_H8)  →  fused (1,512,32,32)
  conv6_3  (1,512,32,32)    →  WG_conv6_3(inst, bg, bi_H8)  →  fused (1,512,32,32)
  conv7_3  (1,512,32,32)    →  WG_conv7_3(inst, bg, bi_H8)  →  fused (1,512,32,32)
      ↓
  conv8_up (1,256,64,64)    →  WG_conv8_up(inst, bg, bi_H4) →  fused (1,256,64,64)
  conv8_3  (1,256,64,64)    →  WG_conv8_3(inst, bg, bi_H4)  →  fused (1,256,64,64)
      ↓
  conv9_up (1,128,128,128)  →  WG_conv9_up(inst, bg, bi_H2) →  fused (1,128,128,128)
  conv9_3  (1,128,128,128)  →  WG_conv9_3(inst, bg, bi_H2)  →  fused (1,128,128,128)
      ↓
  conv10_up (1,128,256,256) →  WG_conv10_up(inst,bg, bi_H)  →  fused (1,128,256,256)
  conv10_2  (1,128,256,256) →  WG_conv10_2(inst,bg, bi_H)   →  fused (1,128,256,256)
      ↓
  output_conv  Conv(128→2, 1×1) + Tanh
      ↓
输出: fused_ab  (1, 2, 256, 256)   ← Huber 损失对比 gt_ab

  当无实例（empty_box=True）时，所有 WG 直接跳过，骨干输出走 output_conv，
  等价于纯全图上色（自动退化为 Stage-1 行为）。
```

**WG 融合位置选择依据：**

| 尺度 | 特征语义 | bbox 信息 |
|------|---------|---------|
| H×W（conv1,10） | 低级边缘/纹理 | bi_H |
| H/2（conv2,9） | 低级纹理/结构 | bi_H2 |
| H/4（conv3,8） | 中级语义 | bi_H4 |
| H/8（conv4-7） | 高级语义/类别 | bi_H8 |

## 损失函数

```
Stage full / instance:
    L = CE_rebalanced(out_class, gt_soft) + 10 × Huber(pred_ab, gt_ab)

Stage fusion:
    L = Huber(fused_ab_H4, gt_ab_H4)     ← 先下采样至 H/4 再计算
```

**CE rebalanced：** 对稀有色彩（如蓝色海洋、金发）给予更高权重，抑制模型退化为灰色。  
**Huber delta=0.01：** 对异常值（错误预测的饱和色）鲁棒，比 L2 更稳定。
